# 🌻 Study Companion App

A warm, supportive productivity and wellbeing companion built for students — combining task management, goal tracking, a timeline view, motivational quotes, and a simple conversational chatbot, all in one place.

## Features

- **💬 Chat Companion** — A rule-based chatbot that responds to common student feelings (stress, tiredness, exam anxiety, procrastination) with supportive, encouraging replies.
- **✅ Tasks** — Add tasks with optional due dates, mark them complete, and delete them.
- **🎯 Goals** — Track longer-term goals separately from day-to-day tasks.
- **📅 Timeline** — Automatically combines upcoming tasks and goals into a single chronological view based on their dates.
- **🌼 Motivation** — A collection of short motivational quotes, shown randomly at the click of a button.

All data is saved locally in the browser (using `localStorage`), so your tasks, goals, and progress persist between visits.

## Technologies Used

- **HTML** – structure and layout
- **CSS** – warm, calming visual theme
- **JavaScript** – tab navigation, task/goal logic, chatbot keyword-matching, timeline sorting, and local data persistence

## How It Works

1. Navigate between tabs (Chat, Tasks, Goals, Timeline, Motivation) using the top navigation bar.
2. Add tasks or goals with an optional date — they'll automatically appear together in the Timeline tab, sorted by date.
3. Chat with the Companion for encouragement — it uses simple keyword matching to detect feelings like stress or tiredness and responds supportively.
4. Tap "Cheer Me Up" anytime for a random motivational quote.

## Note on the Chatbot

This is a lightweight, rule-based chatbot built using keyword matching in JavaScript — not a machine learning model. It's designed as a simple, friendly companion for everyday study motivation, not as a substitute for real support. If you're genuinely struggling, please reach out to someone you trust.

## How to Run It

1. Download or clone this repository
2. Open `StudyCompanion.html` in any web browser
3. Start adding tasks, goals, and chatting with your companion!
